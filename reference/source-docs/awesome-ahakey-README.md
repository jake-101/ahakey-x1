## Awesome AhaKey 是什么？

`awesome-ahakey` 是 AhaKey 社区项目展示仓库。

它用于收录围绕 AhaKey 产生的：

* 第三方客户端
* 小工具和实用脚本
* AI coding workflow
* SDK demo
* 自定义 HEX 玩法
* 按键、拨杆、灯光、OLED 二创
* 使用教程和安装指南
* 桌面 setup、演示视频和社区 showcase
* Claude、Cursor、Codex 等工具集成

如果你基于 AhaKey 做了一个独立项目，不一定需要直接合并进官方 `desktop` 或 `protocol` 仓库。
你可以把它提交到这里，让更多用户看到、学习和 Fork。

## 和其他仓库的关系

| 仓库                                                             | 用途                   | 适合什么内容                                |
| -------------------------------------------------------------- | -------------------- | ------------------------------------- |
| [`desktop`](https://github.com/AhakeyAI/desktop)               | 官方桌面客户端              | 官方客户端 bug fix、功能改进、客户端源码贡献            |
| [`protocol`](https://github.com/AhakeyAI/protocol)             | AhaKey Developer Kit | BLE 协议、SDK、examples、自定义 HEX 构建说明      |
| [`awesome-ahakey`](https://github.com/AhakeyAI/awesome-ahakey) | 社区项目展示               | 第三方项目、workflow、SDK demo、自定义 HEX 玩法、教程 |
| [`firmware`](https://github.com/AhakeyAI/firmware)             | 官方固件说明               | 官方固件 release notes、升级说明、兼容性说明         |
| [`Discussions`](https://github.com/orgs/AhakeyAI/discussions)  | 想法讨论                 | 不确定是否适合提交时，先讨论                        |

简单理解：

```text
官方客户端改动 → desktop
协议 / SDK / examples 改动 → protocol
独立项目 / workflow / SDK demo / 自定义 HEX 玩法 → awesome-ahakey
官方固件版本说明 → firmware
不确定 → Discussions
```

## 什么内容适合提交？

适合提交到 `awesome-ahakey`：

* 独立第三方客户端
* 小工具、脚本、自动化工具
* AI coding workflow
* SDK demo
* 自定义 HEX 玩法展示
* 按键 / 拨杆 / 灯光 / OLED 二创
* 教程、文章、视频
* 桌面 setup
* 非敏感硬件二创展示
* 生态集成项目

不适合提交到 `awesome-ahakey`：

* 官方完整固件源码
* PCB layout
* Gerber
* BOM
* 生产测试资料
* 供应链资料
* 未经授权的受控资料
* API Key、Token、私钥或个人隐私文件
* 无来源说明的第三方代码或资源
* 冒充 AhaKey 官方固件、官方客户端或官方发布版本的项目

如果你的项目涉及生产级硬件资料、底层固件深度调试或特殊合作，请先提交：

👉 [`Hardware Source Access Program`](https://ahakey.com/cn/hardware-source)

## 收录原则

我们更倾向收录：

* 能被别人复用的项目
* 有清楚 README 的项目
* 有截图、视频或 demo 的项目
* 对 AhaKey 用户有启发的 workflow
* 对 SDK、协议或桌面端生态有帮助的项目
* 尊重开源许可证和第三方版权的项目

我们可能暂时不收录：

* 没有说明用途的项目
* 无法判断来源的代码
* 只包含二进制文件、没有说明的项目
* 明显不可运行但没有标注状态的项目
* 可能误导用户认为是官方固件或官方客户端的项目
* 存在安全、隐私或授权风险的内容

---

## 贡献者认可

AhaKey 对贡献的回报，不只是“感谢”和“署名”。

被收录到 `awesome-ahakey` 的项目，有机会获得：

* 作者署名
* 项目展示
* 社区推荐
* 官网 / 社群 / 周报展示机会
* **AhaKey Maker** 等社区称号
* 优先参与软件、SDK、新功能或新产品内测的机会

这些权益不是自动兑换，也不是固定承诺，而是 AhaKey 对长期、高质量贡献者的优先支持和认可。

## What is Awesome AhaKey?

`awesome-ahakey` is the community showcase repository for AhaKey.

It collects projects and resources built around AhaKey, including:

* third-party clients
* tools and utility scripts
* AI coding workflows
* SDK demos
* custom HEX projects
* button, toggle, light, and OLED remixes
* tutorials and setup guides
* desk setups, demo videos, and community showcases
* Claude, Cursor, Codex, and editor integrations

If you built an independent project around AhaKey, it may not need to be merged into the official `desktop` or `protocol` repository.
You can submit it here so more users can discover, learn from, and fork it.

## Curation principles

We prefer projects that:

* are reusable by other users
* have a clear README
* include screenshots, videos, or demos
* provide useful AhaKey workflows or ideas
* help the SDK, protocol, or desktop ecosystem
* respect open-source licenses and third-party copyright

We may not list projects that:

* do not explain their purpose
* contain code with unclear origin
* only provide unexplained binary files
* claim to be complete but are not runnable
* may mislead users into thinking they are official firmware or official clients
* contain security, privacy, or authorization risks

Projects listed in `awesome-ahakey` may receive:

* community titles such as **AhaKey Maker**
* early access opportunities for software, SDK, new features, or new products

These benefits are not automatic guarantees. They are ways for AhaKey to support long-term, high-quality contributors.
